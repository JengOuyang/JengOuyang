# 07 — 術語表

> 人與 Agent 共用的詞彙定義。出現歧義時以本表為準。

## 交易結構（SMC / Price Action）
| 術語 | 定義 |
|---|---|
| **BOS**（Break of Structure） | 順勢突破前一個結構高／低點，確認趨勢延續 |
| **CHoCH**（Change of Character） | 首次反向突破結構，趨勢可能反轉的第一個訊號 |
| **OB**（Order Block） | 大幅反向推動前的最後一根反向 K 棒；價格回測此區常有反應。「已測試」= mitigated |
| **FVG**（Fair Value Gap） | 三根 K 棒形成的價格不平衡區（第一根高點與第三根低點無重疊），本專案要求 ≥ 0.5 ATR |
| **流動性池** | 等高／等低點、前高前低聚集處，止損單密集的價位 |
| **掃蕩**（Liquidity Sweep） | 價格短暫突破流動性池後迅速反轉 |
| **HH/HL/LH/LL** | 更高高點／更高低點（多頭）；更低高點／更低低點（空頭） |
| **POC / VAH / VAL** | Volume Profile 的成交量最大價位／價值區上緣／下緣 |
| **CME 缺口** | CME 比特幣期貨週末休市造成的價格跳空，常被回補 |
| **MSS**（Market Structure Shift，市場結構轉變） | 結構由 HH/HL 轉為 LH/LL（或反向）的那一次確認性突破，代表市場結構本身已經換邊。本專案的用法：**CHoCH 是第一個警訊，MSS 是已確認的轉變**——CHoCH 之後價格必須以收盤價站穩被破壞的結構點外，並回測不破，才升級為 MSS。`htf_bias` 只在 MSS 成立時翻轉，不因單根 CHoCH 翻轉 |
| **型態學**（Chart Patterns） | 古典技術分析的價格型態，本專案與 SMC 並用而非二選一：反轉型態（頭肩頂／底、雙重頂／底、圓弧）、整理型態（三角、旗形、楔形、矩形）、缺口型態（突破缺口、逃逸缺口、竭盡缺口）。每個型態必須可程式化辨識（見 `scripts/patterns.py`）並記錄 `pattern_type`，才能進 AUDIT 的勝率統計與 LAB 的回測 |
| **量價確認** | 型態突破必須有量能配合（突破 K 棒成交量 ≥ 前 20 根均量 × 1.5），否則視為假突破，不提案 |

## 風險與績效
| 術語 | 定義 |
|---|---|
| **R** | 以「初始止損距離」為 1 單位的損益。`R = (出場 − 進場) / (進場 − 初始止損)`，空單反向。棘輪移動止損後**分母不變** |
| **R_net** | 扣除手續費與資金費率後的 R。所有報表預設用這個 |
| **RR**（盈虧比） | 以 TP1 計的預期 R |
| **期望值 Expectancy** | `p×R − (1−p)`，也就是平均 R |
| **Profit Factor** | 總獲利 R ÷ 總虧損 R 的絕對值 |
| **凱利公式** | `f = p − (1−p)/R`（p＝該 setup 滾動勝率、R＝以 TP1 計的盈虧比）。本專案只用 **二分之一凱利**（`kelly_f × 0.5`），且與 **1.5% 上限取小**（T2 山寨幣為 1.0%）：`risk_pct = min(cap, max(0, kelly_f) × 0.5)`。樣本 < 30 筆時 p 以 0.40 代入 |
| **MAE / MFE** | 持倉期間的最大不利／有利偏移（以 R 為單位） |
| **MaxDD** | 權益自高點的最大回撤，以每小時權益曲線計算 |
| **Sharpe** | 日報酬平均 ÷ 日報酬標準差 × √365，無風險利率取 0 |
| **棘輪**（Ratchet） | 止損只能往有利方向移動、永不回退的機制。R0→R1 保本（+1R）→R2 TP1 部分止盈（+2R）→R3 結構／ATR 追蹤→R4；避險情境另有 RH |
| **Walk-forward** | 把歷史切成多段，每段用前段訓練、後段測試，模擬真實的「不知道未來」 |
| **Goodhart 定律** | 當一個指標變成目標，它就不再是好指標。本專案不讓 CHART 看到 Gate 門檻，就是為了防這個 |

## 系統
| 術語 | 定義 |
|---|---|
| **Router** | `router/discord_router.py`，持有 16 隻 Bot 連線並呼叫 Agent 的常駐程式 |
| **切片**（context slice） | 由 `build_context.py` 從 `shared/` 為單一角色生成的規則子集，存於 `agents/<id>/.context/` |
| **憲法** | `shared/CONSTITUTION.md`，全體逐字一致的九條鐵律 |
| **視圖授權** | `shared/view_grants.yaml`，定義每個 Agent 能查哪些資料庫視圖 |
| **盲審** | REDTEAM 只看結論與原始資料、不看被審者推理的審核方式 |
| **hop** | 訊息在 Agent 之間傳遞的次數，≥ 6 強制停止 |
| **preflight** | Router 啟動前的自檢（上下文完整性 + Agent 定義 lint） |
| **exit 3** | 程式對 Router 的約定回傳碼，意思是「這則訊息該交給 LLM 處理」 |
| **T1–T4** | 四層商品宇宙：主流幣／市值前 20／貴金屬／幣股永續 |
| **DEMO / LIVE** | 模擬盤／真錢模式，由 `strategy_params.yaml: mode` 控制 |

## 行銷
| 術語 | 定義 |
|---|---|
| **內容支柱**（Pillar） | 固定的內容類型：每日總經、盤面、週回顧、教育、績效透明 |
| **Reach / Impressions** | 觸及人數／曝光次數（同一人可多次） |
| **Engagement Rate** | `(讚 + 留言 + 儲存 + 分享) ÷ reach` |
| **Save Rate** | 儲存數 ÷ reach。對教育型內容而言比按讚更重要 |
| **兩步發佈** | Meta Graph API 的流程：先建 media container，再 publish |
