# ig-copywriting

## 何時使用
撰寫 IG 貼文文案（繁中、hook、CTA、hashtag、聲明）。

## 輸入 / 輸出契約
- **輸入**：MACRO_BRIEF / HTF_CONTEXT / AUDIT 月報的事實
- **輸出**：文案（hook + 內文 + CTA + hashtags + 聲明）
- **失敗時**：事實無法查證或含進場價 → 不出稿，退回要求資料

## 步驟
1. 前 125 字 = 結論或反直覺數字；短句分段；不用術語堆疊。
2. CTA：儲存／分享／留言問題。
3. hashtag 10–15（大 3、中 7、小 5）；alt text 一句。
4. 結尾固定聲明；不出現進場價／保證／未驗證績效。
